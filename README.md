# CreditRisk Intelligence Platform

## Project Overview

This is a personal learning project to build an end-to-end Credit Risk Analytics platform focused on IFRS 9 Expected Credit Loss (ECL).

The project aims to demonstrate how credit risk data can be analysed and used to estimate Probability of Default (PD), Loss Given Default (LGD), Exposure at Default (EAD), and Expected Credit Loss (ECL).

## Project Objectives

- Understand and analyse credit risk data.
- Build and evaluate Probability of Default (PD) models.
- Develop illustrative LGD and EAD estimates.
- Calculate IFRS 9 Expected Credit Loss (ECL).
- Perform model validation and monitoring.
- Build an interactive application using Streamlit.
- Explore an AI-assisted credit risk analysis feature.

## Technology Stack

- Python
- SQL and DuckDB
- Pandas and NumPy
- Scikit-learn and Statsmodels
- Matplotlib and Seaborn
- Streamlit
- Git and GitHub

## Data and Assumptions

The project uses the public UCI Default of Credit Card Clients dataset.

Some project components, including LGD, macroeconomic scenarios, and certain EAD assumptions, will be simulated for learning purposes.

The dataset's default indicator is based on next-month payment default and should not be interpreted as a direct measure of the Basel 90-days-past-due definition.

## Project Status

Currently in the initial environment setup and version-control stage.

Further development will cover data quality, exploratory analysis, PD modelling, LGD/EAD estimation, ECL calculation, validation, monitoring, and application development.

## Important Disclaimer

This is an educational portfolio project using public data and illustrative assumptions. It is not a production banking system, does not represent actual bank experience, and should not be treated as regulatory or financial advice.
